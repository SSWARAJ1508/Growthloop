# GrowthLoop AI — Frontend Prototype

An AI-powered Growth Engineering Platform demo (SEO + GEO + CRO) built as a pure frontend prototype — no backend, no real API calls, everything runs on mock data with local React state.

## Stack
React + Vite + Tailwind CSS + React Router + Recharts + lucide-react

## Run it
```
npm install
npm run dev
```
Then open the printed localhost URL.

## Build for production
```
npm run build
```
Outputs to `dist/`.

## Pages
- `/` — Dashboard (score cards, growth chart, AI summary, top opportunities, active experiments, activity feed, the Growth Loop)
- `/websites` — Manage tracked websites, add a new one with a simulated analysis flow
- `/websites/analysis` — Full SEO/GEO/CRO breakdown for the selected website
- `/opportunities` — Filterable, expandable list of every detected growth opportunity
- `/agent` — AI Growth Agent chat interface
- `/experiments` — Experiment list
- `/experiments/:id` — Experiment detail with conversion chart and AI interpretation
- `/analytics` — Trend charts and revenue impact
- `/settings` — Profile and notification preferences
